# Game On

Static score card for sports and games (team sizes and placement points).

## GitHub Pages

1. Push this repo to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** (or **master**) and folder **`/ (root)`**, then **Save**.
5. After a minute or two, the site is live at:

   `https://dlcsports.github.io/game-on/`

Open [`index.html`](index.html) locally in a browser to preview.
